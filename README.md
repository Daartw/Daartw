## 📌 Proyectos destacados

### 🃏 Molly TCG — Tienda online de Pokémon TCG

E-commerce completo para Chile hecho con **TypeScript, Next.js, React, Tailwind CSS, SQLite y Docker**: cartas sueltas, sellados, cartas gradeadas y preventas, con panel de administración, pagos con **Webpay (Transbank)**, verificación en dos pasos, inicio de sesión con Google y Facebook, mensajería con clientes, avisos por Telegram/Discord y cumplimiento de la Ley 21.719 de protección de datos. Probado con pruebas automatizadas, pruebas de seguridad y de carga. *(Repositorio privado)*

### 🤖 [Pokémon TCG RAG](https://github.com/Daartw/TCG-rag)

Catálogo de más de **20.600 cartas** y asistente con **inteligencia artificial (RAG)** que responde preguntas sobre cartas, ataques y legalidad, con precios de mercado en vivo. Desarrollado en **Python** y desplegable con **Docker**.

### 📱 [Sanaesencia — App móvil full stack](https://github.com/Daartw/SanaesenciaApp)

Aplicación **Android nativa en Kotlin** con Jetpack Compose, Material 3, MVVM y Clean Architecture, conectada a un backend **Spring Boot en Kotlin** con API REST, JWT y MySQL.

### 🛒 Sistema de Microservicios

Arquitectura basada en microservicios utilizando **Java, Spring Boot, MySQL y Docker**.

### 🐳 Aplicación Full Stack Dockerizada

Aplicación con frontend y múltiples servicios backend utilizando **Docker Compose, MySQL y APIs REST**.

### ☁️ Despliegue Cloud

Implementación de aplicaciones contenerizadas utilizando **Docker y AWS EC2**.
